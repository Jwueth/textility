# Sécurité et données personnelles

Ce dépôt ne doit contenir que la méthode, ses modèles, du code de contrôle et des exemples fictifs. Ne pas ouvrir une issue publique avec un vault, une conversation, un token ou une pièce confidentielle.

Si une donnée sensible est découverte dans une copie publiée : interrompre la diffusion, prévenir le propriétaire du dépôt par un canal privé déjà connu, retirer le contenu exposé et examiner aussi l’historique et les archives. Si un credential est concerné, le révoquer auprès du service ; supprimer le fichier seul ne suffit pas.

Aucun canal privé de signalement dédié n’est configuré par ce kit. Avant une diffusion à grande échelle, le mainteneur choisit et documente ce canal.

Les instructions de l’agent ne remplacent pas des permissions système. Le vérificateur est une aide limitée, pas une certification de sécurité. Voir [les contrôles avant partage](docs/09-maintenance-securite.md).
