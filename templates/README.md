# Modèles à adapter

Six modèles, sans macros ni plugin requis. Copier le fichier voulu, choisir un titre unique, renseigner les sections utiles et retirer les indications devenues inutiles.

- [Contrat d’intervention](Contrat-intervention.md) : préciser résultat, mandat et échanges ; pas de nouveau formulaire pour une demande simple.
- [Proposition](Proposition.md) : préparer une décision sans la présumer.
- [Référence](Reference.md) : préparer une future référence ; le modèle reste une proposition en attente d’approbation.
- [Décision](Decision.md) : consigner l’arbitrage exact ; champs d’approbation vides au départ.
- [Reprise](Reprise.md) : cache non autoritatif, avec périmètre de revue et liens.
- [Trace](Trace.md) : consigner le résultat et les contrôles réellement observés.

Les métadonnées suivent [le schéma du démonstrateur](../docs/02-conventions.md), pas une norme obligatoire pour un vault existant. Les champs de validation sont volontairement vides. Ne jamais copier les approbations fictives des exemples dans un document réel.
